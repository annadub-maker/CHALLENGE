## Hidden code

The secret code is 4 digits long. Visitors enter it on the `/code` page.

- **Digit 1 (`2`), Workshops section:** click or tap any workshop image 3 times.
  The first two clicks make the image glitch. On the third, a glowing `2` labelled
  "digit #1" appears over the image for 4 seconds.
- **Digit 2 (`7`), Team section:** the green `//` before "Check these superheroes"
  is a forgotten code comment. Hover it, tab to it or tap it, and it shows
  `// TODO: remove digit #2 = 7`. The browser console also shows CCK ASCII art
  with hints for digits 1 and 2.
